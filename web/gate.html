No AI and no login are involved. The guard only checks each number against the solver's own results, and it never does any math of its own, so it cannot talk itself into letting a close-but-wrong number through.

One limit, stated plainly: the check certifies that every number came from the solver. It does not certify that the sentence around the number is true.
